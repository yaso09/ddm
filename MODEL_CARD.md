# Model Card — DDM (Distance-Decomposed Model)

## Model

- **Type:** Causal transformer language model with a learned distance gate
  $g(k)$ applied pre-softmax in log-space, plus per-layer segment memory.
- **Architecture:** $d_{\text{model}} = 256$, 2 layers, 8 heads, ALiBi
  slopes $m_h = 2^{-8h/H}$, gate MLP `Linear(1,16) → ReLU → Linear(16,1) →
  sigmoid` shared across heads, memory = detached mean hidden of previous
  block prepended as one K/V token. ≈ 13.3M parameters.
- **Tokenizer:** GPT-2 BPE (vocab 50,257).

## Intended Use

Research on *how* attention should weight history by distance: whether a
data-learned distance profile beats fixed biases (ALiBi), which heads
specialize to which distances, and whether position-bucket perplexity
improves. Not intended for production inference.

## Training

- **Data:** WikiText-2 raw (train/val/test), 128-token blocks, causal LM
  objective.
- **Optimizer:** AdamW, lr 3e-4, batch 64, cross-entropy.
- **Hardware:** CUDA or CPU (auto-detected); typical run < 1 hour on
  consumer GPUs.
- **Seeds:** each experiment repeated over seeds {0, 1} (configurable).

## Known Limitations

- Gate is shared across heads (per-head gates are a natural extension).
- Segment memory is a single summary vector per layer (lossy).
- Evaluated only on WikiText-2 at 128-token blocks.

## Ethical Considerations

Standard NLP research artifact; trained on public text data (WikiText-2).
No personal data, no fine-tuning on user content.
